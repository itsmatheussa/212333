# ObyBlox — Site de links

## Publicar na Vercel
1. Extraia este ZIP.
2. Em vercel.com, clique em **Add New → Project → Import** e selecione esta pasta (ou suba no GitHub e importe).
3. A Vercel detecta o framework automaticamente. Build: `bun run build`. Nenhuma configuração extra é necessária.

## Rodar localmente
`bun install` e depois `bun run dev`.
