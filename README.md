# ObyBlox — Link na bio

Site de links da ObyBlox (loja + Discord), pronto para publicar na Vercel.

## Como publicar na Vercel
1. Extraia este ZIP.
2. Na Vercel, clique em "Add New → Project" e importe a pasta extraída (ou suba no GitHub e importe o repositório).
3. A Vercel detecta o framework automaticamente (Vite). Não precisa mudar nada.
4. Clique em Deploy.

## Rodar localmente
```
bun install
bun run dev
```

Build de produção: `bun run build`
